# SBI Reconciliation Workspace — Invoice Generation + GST Report

**Stage:** Combined QA integration branch, 24 Nov 2026. **Not a production release.**

## Delivered code
- Invoice creation and validated shipment annexures from the uploaded six-column
  layout: Dispatch Date, LR No, Packet Ref No, Consignee, Weight, Amount.
- Taxable amount = annexure sum; CGST 9%, SGST 9% using Decimal HALF_UP;
  exact total = taxable + CGST + SGST. New invoices do not use bank payments.
- Verified SBI branch master is required. Read-only master lookup is provided
  through an isolated private PostgreSQL table to be populated *only* by an
  approved mapping from the existing database. No fabricated branch data.
- Immutable invoice and individual shipment registry, unique invoice number,
  atomic finalize and duplicate protection. No reconciliation table changes.
- Reports TAB: Invoice Preview/Finalize plus Generate GST Report (.xlsx).
- GST exports only finalized, verified invoices using the exact 16-column
  Workstream D v2.7 contract with duplicate Branch Code headers. F/H SOL
  remains text. J–N from stored invoice amounts; all other columns from
  the verified database snapshot recorded at finalization. Service month
  is independent of issue date.
- Feature and finalize endpoints are OFF unless separately enabled.
  Every endpoint is protected by Firebase session plus explicit creator/viewer
  role; POST uses existing CSRF protection.
- Synthetic automated combined QA includes API, finance arithmetic, exact
  GST headers, duplicate rejection, immutable SQL, and an isolated PostgreSQL
  service. No live bank or customer transactions are used.

## Environment (private runtime only)
- `SBI_INVOICE_GST_ENABLED=1` enables API reads/previews.
- `SBI_INVOICE_GST_FINALIZE_ENABLED=1` allows invoice-only finalizations.
- `SBI_INVOICE_GST_DEPLOYMENT_MODE=ISOLATED_QA` for QA. Explicit owner
  cutover is required before any `APPROVED_LIVE` deployment.
- `SBI_INVOICE_GST_DATABASE_URL` is a private PostgreSQL DSN with
  schema-limited access. Never place credentials in GitHub source.
- Creator custom claim: `sbi_invoice_creator=true`; GST export uses
  existing `sbi_report_viewer=true` and `dil_dashboard=true` role.

## Routes
- `GET /api/invoice-gst/branches` — verified branch picker
- `POST /api/invoice-gst/preview` — no database writes
- `POST /api/invoice-gst/finalize` — record one approved invoice + annexure
- `GET /api/invoice-gst/invoices/<invoice_no>` — registered invoice
- `GET /api/invoice-gst/gst.xlsx?month=YYYY-MM` — approved GST workbook
